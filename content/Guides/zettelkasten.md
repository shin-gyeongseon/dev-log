# 옵시디언 기반 제텔카스텐(Zettelkasten) 지식 관리 방법론

개인 지식 관리(PKM, Personal Knowledge Management)와 '세컨드 브레인(Second Brain)' 구축을 위한 제텔카스텐 방법론을 정리합니다.

---

## 1. 제텔카스텐(Zettelkasten)이란?

독일 사회학자 니클라스 루만(Niklas Luhmann)이 고안한 메모 상자 시스템으로, 정보의 계층적 분류 대신 **원자적 노트(Atomic Note)**와 **상호 연결(Hyperlinks)**을 통해 새로운 아이디어를 창발시키는 지식 구축 체계입니다.

> [!NOTE] 제텔카스텐의 3대 노트 유형
> 1. **임시 메모 (Fleeting Notes)**: 일상 중 번뜩이는 생각이나 아이디어를 빠르게 적은 메모
> 2. **문헌 메모 (Literature Notes)**: 책, 아티클, 논문 등을 읽고 나의 언어로 요약한 메모
> 3. **영구 메모 (Permanent Notes)**: 다른 노트들과 위키링크로 연결되어 독립적인 지식 가치를 가지는 핵심 노트

---

## 2. 옵시디언(Obsidian)에서의 실천 전략

```
[원천 자료 (책/아티클)] ──▶ [문헌 메모]
                                │
                                ▼
                       [영구 메모 (원자적)]
                                │
            ┌───────────────────┴───────────────────┐
            ▼                                       ▼
     [[위키링크 상호 연결]]                     #태그 분류
            │                                       │
            └───────────────────┬───────────────────┘
                                ▼
                     [인터랙티브 지식 그래프]
```

### 1) 한 노트에는 하나의 개념만 (원자성)
노트 하나가 너무 방대해지면 상호 참조가 모호해집니다. 명확한 하나의 개념 단위로 문서를 분리하고 양방향 링크로 묶습니다.

### 2) 폴더보다 링크(Links)와 맵 오브 컨텐츠(MOC) 활용
깊은 계층의 폴더 구조는 정보의 고립(Silo)을 만듭니다. 상위 개념을 정리하는 목차 노트(MOC, Map of Content)를 만들고 관련 노트를 링크합니다.

---

## 3. 웹 블로그(Quartz)와의 시너지

옵시디언 볼트의 마크다운 파일들을 그대로 GitHub Pages로 배포함으로써:
- 내가 정리한 지식을 인터넷의 누구와도 손쉽게 공유
- 웹 상에서도 인터랙티브 그래프 뷰(Graph View)와 백링크(Backlinks)를 그대로 탐색 가능
- 검색창(`Ctrl + K`)을 통해 어디서든 내 지식 베이스 접근
