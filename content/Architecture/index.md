# 🏛️ Architecture & System Design

유지보수성과 확장성이 높은 소프트웨어 구조, 클린/육각형(Hexagonal) 아키텍처, 도메인 주도 설계(DDD), 대규모 분산 시스템 및 마이크로서비스 설계 패턴을 다룹니다.

---

## 🎯 학습 로드맵 & 핵심 주제

- **소프트웨어 설계 원칙**: SOLID, 객체지향 설계(OOD), 클린 아키텍처, 헥사고날 아키텍처
- **도메인 주도 설계 (DDD)**: 엔티티, 밸류 객체, 애그리게이트, 유비쿼터스 언어, Bounded Context
- **마이크로서비스 아키텍처 (MSA)**: 서비스 분리 기준, API 게이트웨이, Saga 패턴, 이벤트 소싱/CQRS
- **대규모 분산 시스템**: 분산 캐시, 메시지 큐(Kafka/RabbitMQ), 분산 트랜잭션, 데이터 정합성
